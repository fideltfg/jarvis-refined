# Notes for AI agents

## Changelog (required)

Every change you make to this repository must be recorded in
[CHANGELOG.md](CHANGELOG.md) before you finish:

- Add a short, user-facing entry under **Unreleased** in the right group
  (Added, Changed, Fixed, Removed, Security).
- Describe what changed for the user or operator, not how the code changed.
- When committing, move the committed entries under a heading for today's date.
- Skip only changes with no visible effect (pure test or formatting edits).
